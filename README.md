# 🚀 Avik's WebOS

A lightweight, high-performance WebOS built with HTML, CSS, and JavaScript. Features interactive windows, custom themes, and GPU-accelerated window physics.

## ✨ Features
* the window's are interactive so whenever they are moved, they wiggle.
* **Custom Themes:** Independent Light and Dark mode states supporting custom MP4 and image wallpaper uploads. Also both theme got their own icon pack
* **App Suite:** 
  * Sticky Notes app
  * Local Music Player with custom file loading
  * Theme & Settings Manager
 
  * for now, only basic apps are made, upgrades will come soon. oh almost forgot... a cool looking clock.

## 🛠️ Tech Stack
* HTML5
* CSS3 (Flexbox, Backdrop Filters, Keyframe Animations)
* Vanilla JavaScript (`requestAnimationFrame`, Web APIs)
